# Utilities

- `kv.py` - JSON-backed key-value store with load/save support.
- `primes.py` - Prime-number checker for integers.
- `wordcount.py` - Command-line helper for counting common words in a text file.
- `statistics_utils.py` - Mean, median, mode, and sample standard deviation helpers.
- `palindrome.py` - Palindrome checker that ignores case and non-alphanumeric characters.
- `roman.py` - Integer-to-Roman-numeral converter for values from 1 to 3999.
